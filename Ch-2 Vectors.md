# Vectors : geometry and algebra
- Geometry : 
	- A line determined by magnitude and direction.
	- Does not include a starting and ending point.
- Algebra : 
	- A vector is an ordered list of numbers.
	- numbers in the vector is called *dimensionality.*

# Vector addition and subtraction
- Geometry : 
	- triangular addition using head and tail.
	- addition is commutative : a + b = b + a.
	- subtraction : either triangular method (or) reverse the direction of second vector and then add.
	- subtraction is not commutative because of direction.
- Algebra : 
	- element wise addition or subtraction.

# Vector-Scaler Multiplication
- Geometry : 
	- Scaling a vector means making it shorter or longer without changing it's angle.
- Algebra : 
	- multiplying all the elements of the vector by the scaler.
	- commutative : $\lambda v = v\lambda$
